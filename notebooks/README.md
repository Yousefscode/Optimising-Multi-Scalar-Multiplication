# Notebooks

`dissertation_notebook.ipynb` is the original Google Colab notebook submitted
with the dissertation, kept unchanged (including its saved outputs) as a record.

Its bucketing and Pippenger implementations contain the weighting bug described
in the main README's *Post-submission correction*. Use the tested code in
[`../msm`](../msm) for anything new.
